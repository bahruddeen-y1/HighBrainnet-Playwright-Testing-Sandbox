## 1. ภาพรวม Role ในระบบ

ระบบ HighBrainnet มี **2 role หลัก** ได้แก่ **ครู (Super Admin)** และ **นักเรียน** โดยไม่มี role กลางหรือ moderator

---

## 1.1 ครู (Super Admin)

ครูเป็น admin เพียงคนเดียวที่จัดการทุกอย่างในระบบ ไม่มีข้อจำกัดด้านสิทธิ์

### สิทธิ์การจัดการเนื้อหา
- สร้าง แก้ไข ลบ (soft delete) คอร์ส บท หัวข้อ วิดีโอ
- อัปโหลดวิดีโอผ่าน Bunny.net CDN พร้อม progress bar
- สร้างและจัดการ version ของคอร์ส (Course Versioning)
- กำหนดราคาและ package bundle อิสระต่อคอร์ส
- สร้างแบบทดสอบ quiz และ mock exam พร้อมกำหนด timer
- เปิด/ปิดการมองเห็นของบทเรียนแต่ละรายการ

### สิทธิ์การจัดการนักเรียน
- approve การชำระเงินและการเข้าถึงคอร์ส
- unlock อุปกรณ์นักเรียน (single device control)
- ระงับหรือคืนสิทธิ์นักเรียน
- กรอกและจัดการเครดิตสอบติดของนักเรียนแต่ละคน
- กำหนดว่าแสดงชื่อจริงหรือนามแฝงของนักเรียนบนหน้าเว็บสาธารณะ
- กำหนดอายุการเข้าถึงคอร์สต่อนักเรียนแต่ละคน (ตลอดชีพหรือมีวันหมดอายุ)

### สิทธิ์ Dashboard และรายงาน
- ดู KPI หลัก: ยอดขายวันนี้/เดือนนี้ นักเรียนใหม่ คอร์สขายดี
- export รายงานเป็น Excel (`.xlsx`) CSV และ PDF
- กรองรายงานตามช่วงเวลา คอร์ส และชั้นเรียน
- รับแจ้งเตือนผ่าน Line Notify ทันทีเมื่อมีการชำระเงิน

---

## 1.2 นักเรียน (Student)

นักเรียนเข้าถึงเฉพาะเนื้อหาที่ซื้อแล้ว ไม่มีสิทธิ์จัดการระบบใดทั้งสิ้น

- ดูวิดีโอบทเรียน DRM protected บน **1 อุปกรณ์เท่านั้นพร้อมกัน**
- ข้ามบทเรียนได้อิสระ ไม่บังคับเรียนตามลำดับ
- ทำแบบทดสอบ quiz และ mock exam (ครูกำหนดว่ามี timer ไหม)
- ดู progress ของตัวเองในแต่ละคอร์สและบท
- ดาวน์โหลดใบเซอร์ติฟิเกตเมื่อเรียนจบคอร์ส
- ชำระเงินผ่าน QR PromptPay และเข้าถึงคอร์สได้หลัง approve
- รับแจ้งเตือนเมื่อมี version ใหม่ของคอร์สที่ซื้อไว้
- ใช้ Line กลุ่มสำหรับ Q&A กับครู (ไม่มีในระบบ)
