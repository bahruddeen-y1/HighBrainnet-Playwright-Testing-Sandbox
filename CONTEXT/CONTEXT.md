## 2. โครงสร้างเนื้อหา

### 2.1 ชั้นเรียนและคอร์ส

- **ประถมปลาย (ป.4-6):** คณิตพื้นฐาน + ตะลุยโจทย์สอบเข้า ม.1 (รวมในคอร์สเดียว)
- **มัธยมต้น (ม.1-3):** คณิตพื้นฐานตามหลักสูตร
- **มัธยมปลาย (ม.4-6):** คณิตพื้นฐานตามหลักสูตร
- วิดีโอถ่ายใหม่ทั้งหมด ยังไม่มีไฟล์เดิม

### 2.2 Pricing Model

- ซื้อทีละคอร์ส ครูกำหนดราคาเอง
- ครูสร้าง package bundle รวมหลายคอร์สได้
- ระบบ Course Versioning: **แนวทาง B** — มี version และราคา upgrade
- นักเรียนเก่าจ่ายส่วนต่างถ้าอยากอัปเกรด ไม่บังคับ

## 3. Feature ทั้งหมด

### 3.1 ระบบวิดีโอ
- รองรับ 1080p / 720p / 480p
- DRM ป้องกันดาวน์โหลด
- จำตำแหน่งที่ดูค้างไว้ (resume watching)
- Single device: 1 นักเรียน 1 อุปกรณ์พร้อมกัน kick อัตโนมัติ
- ครู unlock อุปกรณ์ผ่าน Line แล้ว admin panel

### 3.2 ระบบแบบทดสอบ
- Quiz ก่อนเรียนและหลังเรียนแต่ละบท
- Mock Exam mode: ครูกำหนดว่ามี timer และกี่นาที
- ตรวจอัตโนมัติ แสดงเฉลยพร้อมคำอธิบายทันทีหลังส่ง
- บันทึกคะแนนทุกครั้งที่ทำ ดูประวัติย้อนหลังได้

### 3.3 ระบบ Payment
- QR PromptPay ผ่าน GB Prime Pay (fee 1.5%)
- Webhook รับการชำระ → แจ้งเตือนครูทาง Line Notify ทันที
- ครู approve การเข้าถึงคอร์ส
- มีระบบ approve manual สำรอง กรณี webhook ล้มเหลว
- Export รายงานการชำระเงินตามช่วงเวลาได้

### 3.4 ระบบเครดิตสอบติด
- ครูกรอกข้อมูล: ชื่อนักเรียน โรงเรียนที่สอบติด ปีการศึกษา
- ครูเลือกว่าแสดงชื่อจริงหรือนามแฝงต่อนักเรียนแต่ละคน
- แสดงบนหน้า **"ผลสอบนักเรียน"** สาธารณะ
- Export รายชื่อสอบติดเป็น Excel ได้

### 3.5 ระบบ Export รายงาน
- ครูกด export เท่านั้น
- **Excel (.xlsx):** ยอดขาย, รายชื่อนักเรียน, ประวัติชำระ, คะแนน quiz, รายชื่อสอบติด
- **PDF:** ใบเสร็จ, ใบเซอร์ติฟิเกต
- **Filter:** ช่วงเวลา (วัน/สัปดาห์/เดือน/กำหนดเอง), แยกตามคอร์ส/ชั้นเรียน

### 3.6 ระบบ Soft Delete
- ทุก entity มี `is_deleted` + `deleted_at`
- ครู restore ได้ทุกเมื่อ
- แจ้งเตือนก่อนซ่อนว่ามีนักเรียนกี่คนที่ใช้งาน
- นักเรียนที่ซื้อไปแล้วยังเข้าถึง version เดิมได้แม้ครูซ่อนเนื้อหา

### 3.7 Dashboard Admin
- KPI: ยอดขายวันนี้/เดือนนี้, นักเรียนใหม่, คอร์สขายดี Top 3
- กราฟยอดขาย 30 วันล่าสุด
- รายการรอ approve ทั้งหมด

### 3.8 UX/UI
- **Mobile first:** ออกแบบสำหรับมือถือก่อน
- โทนสี `#85B2D5` (HighBrainnet Blue) ตาม brand
- **Font:** Kanit สำหรับหัวข้อ, Sarabun สำหรับเนื้อหา
- ขนาดตัวอักษรขั้นต่ำ 14px (เหมาะกับเด็ก)
- ปุ่มขนาดใหญ่ min 44px touch target
- Feedback ทันที: ตอบถูก/ผิด แสดงผลทันที
- Gamification ปรับตามชั้นเรียน: ประถมเยอะ, ม.ปลายน้อย
- Progress bar ทุกบทเรียน
- Loading indicator ทุกครั้งที่รอ
