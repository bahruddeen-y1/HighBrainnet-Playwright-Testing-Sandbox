## 1. ภาพรวมโปรเจกต์

**HighBrainnet** คือระบบคลาสออนไลน์สร้างขึ้นด้วย claude code เพื่อเป็นพื้นที่จำลองการทดสอบด้วย Playwright และอัปสกิลที่เกี่ยวข้องด้วยตนเอง

## 2. บริบท AI

**โปรเจ็คนี้มุ่งเน้นเพื่อเรียนรู้ Playwright** AI เป็นแค่ผู้ช่วยถามตอบ การหาข้อมูล และการสร้าง Sandbox เท่านั้น
